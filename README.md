# OVER.INDEX

Overwatch 영웅의 역할, 하위 역할, 스킬 정보를 한눈에 확인할 수 있는 영웅 탐색 웹 애플리케이션 입니다.

OverFast API를 활용하여 실제 Overwatch 영웅 데이터를 불러오고, 역할별 영웅과 픽률 TOP5를 보여주며 각 영웅의 상세 정보와 스킬 영상을 확인할 수 있도록 구현했습니다.

---

### 주요 기능

- 영웅 목록 조회
- 영웅 상세 정보 조회
- 영웅 포지션별 조회
- 영웅 역할 및 서브 역할 정보 제공
- 영웅 능력치 정보 제공
- 영웅 스킬 정보 제공
- 영웅 간 상성 정보 제공

- 맵 목록 조회
- 맵 상세 정보 조회
- 맵 포인트별 정보 제공
- 맵별 추천 / 비추천 영웅 조회
- 포인트별 추천 / 비추천 영웅 조회

- 영웅 및 맵 검색

## 기술 스택

### Frontend

| 기술                 | 사용 목적                                            |
| -------------------- | ---------------------------------------------------- |
| React                | 컴포넌트 기반 UI 구성 및 페이지 개발                 |
| React Router         | 페이지 간 라우팅 및 동적 URL을 통한 상세 페이지 구현 |
| Tailwind CSS         | 반응형 레이아웃 및 UI 스타일링                       |
| Swiper               | 영웅 카드 및 콘텐츠를 슬라이드 형태로 구현           |
| React Icons          | UI에 필요한 아이콘 구현                              |
| React Loader Spinner | API 데이터 로딩 상태를 시각적으로 표시               |
| Vite                 | React 프로젝트 개발 환경 및 빌드 도구                |

### API

| API            | 사용목적                                                                                                                   |
| -------------- | -------------------------------------------------------------------------------------------------------------------------- |
| OverFast API   | 영웅 기본 정보, 초상화, 스킬, 능력치, 역할 및 서브 역할, 맵 기본 정보, 맵 이미지, 게임 모드, 영웅 통계 및 픽률 데이터 조회 |
| OverPicker API | 영웅 간 카운터 및 시너지 정보, 맵 포인트 정보, 포인트별 추천 / 비추천 영웅 데이터 조회                                     |
